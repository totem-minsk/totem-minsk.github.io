# Сайт спортивного комплекса «Тотем»

> Тотем — охота за удовольствием

Одностраничный сайт спортивного комплекса «Тотем» (Минск, ул. М. Богдановича, 78). Здесь есть тренажёрный зал, кардиозона, 12 видов массажа, хамам, кедровая бочка и SPA. Сайт нужен, чтобы продавать абонементы в зал и на массаж. Посетитель связывается с клубом через мессенджеры или по телефону.

Подробное ТЗ, факты о клубе и правила разработки описаны в [CLAUDE.md](./CLAUDE.md).

---

## Стек

- HTML5, CSS3 (переменные, Grid, Flexbox), vanilla JavaScript
- Без фреймворков, сборщиков и CMS: сайт статический, цены на нём не показываются
- Шрифты Tektur (заголовки) и Golos Text (текст) подключены локально из `assets/fonts/` (woff2)
- Карта: Яндекс.Карты (загружается по требованию) и ссылка на Google Maps

## Локальный запуск

Сборка не нужна. Достаточно открыть `index.html` в браузере. Для корректной работы карты лучше запустить локальный сервер из корня проекта:

```bash
# Python
python3 -m http.server 8000

# или Node.js
npx serve .
```

После запуска сайт откроется по адресу http://localhost:8000

## Как изменить контент

| Что | Где |
|---|---|
| Тексты блоков | `index.html`, соответствующая `<section>` |
| Телефон и ссылки мессенджеров | `index.html`: поиск по `375293795261` |
| Текст в заготовленных сообщениях | атрибут `data-msg` у кнопок (ссылка WhatsApp собирается в `main.js`) |
| Виды массажа и SPA | блок `#massage` в `index.html` |
| Цвета | `assets/css/style.css`, переменные в `:root` |
| Часы работы | блок «Контакты» и разметка Schema.org в `<head>` |

Цены на сайте не публикуются, поэтому при изменении прайса править сайт не нужно.
